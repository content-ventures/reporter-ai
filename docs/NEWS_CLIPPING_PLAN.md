# Seafood editorial clipping implementation

The newsroom's “Especificação Técnica de Filtragem e Coleta (clipping editorial)”, supplied by Fabi, is the current editorial specification. Its global domain exclusion takes precedence over older workspace guidance.

1. Encode the six segments, PT/EN/ES keywords, business axes, noise exclusions and source matrix in the domain. Apply the domain exclusion to all clipping inputs and at the database write boundary. Apply the Seafood taxonomy in the Seafood workspace; unrelated client workspaces keep their own search configuration.
2. Rotate the six segments in Portuguese, English and Spanish using the existing worker budget. A full sweep is 36 requests; a lower daily cap carries the cursor into the next budget period. Combine subject and business terms for open web searches. Use [Tavily source preferences](https://docs.tavily.com/documentation/api-reference/endpoint/search) so the supplied sources rank ahead while other outlets and primary authorities can still appear. Keep feed registration and its limits separate from web search.
3. Classify from available source text before writing a Seafood item. Keep one primary segment. Use exact links and conservative headline similarity to group coverage; retain all available source links and surface an official or better documented reference without changing the existing record identity. Keep search snippets and paywalled previews identified as excerpts.
4. Default Seafood collection and its Radar to 24 hours. Offer 48 and 72 hours, one week, one month and one year. A Radar filter displays collected items; changing the collection window requests a new web search. Feeds only expose what the publisher still serves. Neither action guarantees an exhaustive archive. Existing story identities and decisions are retained; historical stories are not retroactively assigned a segment.
5. Verify locally with domain, provider, database and repository checks. Before providing operational access, validate the intended environment with real PT/EN/ES examples, a blocked domain, an inaccessible article and the same story in several outlets. Ask the newsroom to check classification and source preferences on that sample. Remote delivery follows the development harness.
